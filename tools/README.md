# כלים לעדכון קליל
- `src/index.html` – קוד המקור (מקור האמת). `index.html` / `dorin/index.html` נבנים ממנו.
- תוכן יומי לאבוקי: להוסיף רשומות לפני הסמנים `/*KBD_END*/` (שאלות-תשובות), `/*DFACT_END*/` (עובדות), `/*DCHAL_END*/` (אתגרים) ב־src/index.html.
  פורמט KBD: `{c:'תזונה',t:'כותרת',k:['מילת מפתח',...],a:\`תשובה\`},`  — קטגוריות קיימות: תזונה, צום, כושר, שינה, משקל, בריאות, סגנון חיים, הגוף מבפנים.
- שחרור: `python3 tools/release.py "הערות שחרור"` — מעלה APPV, בונה את שני הערוצים, בודק תחביר, מעדכן version.json ודוחף.
- לא לגעת ב־devora/ וב־*.apk.
