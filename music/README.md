# Music

Tracks from **Open Lo-Fi** (https://github.com/btahir/open-lofi), released under **CC0 1.0 Universal** (public domain).
Re-encoded to 96 kbps with loudness normalization for in-app background playback.


Workout tracks `x-*.mp3`: Abstraction / Tallbeard Studios (Ben Burnes) and DJ CrisP, via the CC0 Media Library (https://github.com/jfpx/cc0-media-library), released under **CC0 1.0**.
`playlist.json` controls what the app plays; the workout set rotates every 3 days.

More background tracks from **Open Lo-Fi** (CC0). Workout track `x-basement-groove-86.mp3` from Open Lo-Fi (CC0).

Workout tracks `x-th-*.mp3`: **music by Tanner Helland** (https://github.com/tannerhelland/free-music), licensed under **Creative Commons Attribution 4.0** (https://creativecommons.org/licenses/by/4.0/). Trimmed to 4 minutes and loudness-normalized.
